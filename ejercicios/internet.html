¿Que es Internet?★

Internet es un conjunto descentralizado de redes de comunicaciones interconectadas, que utilizan la familia de protocolos TCP/IP, lo cual garantiza que las redes físicas heterogéneas que la componen constituyen una red lógica única de alcance mundial

¿Que son los Proveedores de Internet?★

Un ISP (Internet Service Provider o Proveedor de Servicios de Internet) es una empresa que te brinda acceso al internet. Piénsalo como un portal que conecta tu computadora, smartphone u otro dispositivo con el vasto mundo en línea. Los ISPs también ofrecen servicios adicionales como correo electrónico, alojamiento web y más. Al pagar una suscripción a un ISP, básicamente estás alquilando su red para conectarte a internet.

Tipos de Proveedores de Internet★

Los proveedores de servicios de internet (ISP) se clasifican principalmente según la tecnología que utilizan para llevar la señal hasta los hogares o empresas:

  • Fibra Óptica: Utiliza filamentos de vidrio para transmitir datos a la velocidad de la luz, ofreciendo la máxima estabilidad y simetría de subida y bajada.
  • Cable Coaxial (Banda Ancha): Emplea redes de televisión por cable de cobre combinadas con nodos de fibra; es rápido y muy común, aunque la velocidad puede variar en horas pico.
  • Satelital: Recibe la señal directamente desde el espacio mediante una antena parabólica. Es ideal para zonas rurales o extremadamente remotas sin infraestructura terrestre.
  • Internet Móvil / Inalámbrico (4G/5G y WISP): Utiliza torres de telefonía celular o antenas locales para repartir la señal por ondas de radio sin necesidad de cables físicos en el domicilio

Carpeta Local vs Carpeta remota★

Una carpeta local se encuentra almacenada directamente en el disco duro de tu propia computadora, mientras que una carpeta remota está ubicada en otro equipo o en un servidor remoto en la nube al que accedes a través de una red o internet.

Que es Experiencia de Usiario Vs Interfaz de usuario⇑

Experiencia de usuario

La User Experience, o más conocida a través del término UX, hace referencia a la experiencia que el propio usuario experimenta al visitar e interactuar con una solución digital, ya sea una página web o aplicación. De esta manera, el principal objetivo de la UX es garantizar la mejor experiencia posible al usuario y por ello, el diseño UX se centra principalmente en el usuario, anticipando y pensando siempre en sus necesidades, habilidades o incluso sus limitaciones. Para poder garantizar una buena user experience se debe incluir un contenido útil, usable, que llame la atención del usuario y, sobre todo, debe presentar una experiencia intuitiva. Para conseguir esto, será necesario realizar un análisis de cómo el usuario interactúa antes, durante y después de las principales acciones en la web o en la aplicación. En este análisis, se deberán conocer las motivaciones y las necesidades más importantes para el usuario para, así, poder diseñar una interfaz y unos contenidos a través de los cuales se puedan establecer mayores interacciones.

Interfaz de usuario

Ésta es uno de los elementos que condiciona la UX ya que es lo que un usuario visualiza y utiliza para poder establecer la interacción que comentamos anteriormente. De esta forma, la UI hace referencia a interfaz visual con la que el usuario va a interactuar con el producto digital de la empresa y es por este motivo que, normalmente, la User Interface y el UI design está conceptualizada por un equipo de diseñadores con alta experiencia y conocimientos. Este equipo de profesionales se encarga de crear el esquema de los contenidos de la página web o la app, es decir, selecciona y distribuye los elementos a incluir en la interfaz del usuario. Además, también desarrollan el diseño UI por lo que seleccionan los colores, las tipografías y los elementos visuales necesarios. La UI se encarga de que cada uno de los elementos que forman parte del diseño sean claros, se adapten a los diferentes sistemas operativos o dispositivos, y cumpla sobre todo con los objetivos principales, es decir, que sea atractivo, útil y mejore la experiencia del usuario en los diferentes productos digitales.

Que es Maquetación Web★

La maquetación web es una disciplina frontend mediante la cual se define y posiciona el contenido de páginas web, atendiendo a una estructura adecuada para la lectura y una presentación de la información atractiva. El trabajo de maquetación web incluye básicamente dos partes. Primero, la definición de un marcado adecuado para el contenido que se debe presentar, con un HTML que permita de una manera versátil la aplicación de estilos. Segundo, la aplicación de reglas de estilo, mediante CSS, que permitan posicionar los elementos dentro de un layout y que apliquen un aspecto atractivo y de fácil lectura del contenido. Existen profesionales que se dedican específicamente a la maquetación web, los cuales deben tener un conocimiento completo de HTML y CSS. Estos profesionales deben conocer las etiquetas HTML disponibles para la especificación del contenido y las etiquetas de control, que sirven para definir cómo el navegador y otros robots han de entender y procesar la web. También deben tener un conocimiento sólido de CSS, que permitan trabajar con el lenguaje de una manera rápida y optimizada.

Que es el Modelo de cajas en HTML y CSS ★

Html

El modelo de cajas (Box Model) es el sistema que usan los navegadores para interpretar cada elemento HTML como una caja rectangular que controla su diseño y espacio en la pantalla

css

El modelo de caja (o box model) en CSS es un sistema que usa el navegador para interpretar cada elemento HTML como una caja rectangular compuesta por cuatro capas o áreas principales
